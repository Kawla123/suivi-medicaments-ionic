✨ Fonctionnalités
✅ Suivi des médicaments - Ajoutez et gérez vos médicaments facilement
📅 Rappels intelligents - Recevez des notifications pour vos prises de médicaments
📊 Historique - Consultez un historique complet de vos prises
👥 Multi-profils - Gérez plusieurs profils utilisateurs
🔐 Sécurité - Authentification Firebase sécurisée
💾 Synchronisation - Vos données synchronisées en temps réel via Firebase
📱 Design responsive - Interface adaptée à tous les appareils
📦 Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés :

Node.js (v16.0 ou supérieur)
npm (v7.0 ou supérieur) ou yarn
Ionic CLI (v6.0 ou supérieur)
Angular CLI (v12.0 ou supérieur)
Un compte Firebase avec un projet créé
